# 🕒 Date-fns Clock Widget

A modern digital clock widget built with **Next.js 15**, **React 19**, and **date-fns**, displaying real-time hours, minutes, seconds, AM/PM, and full date with smooth sliding number animations. The UI is clean, responsive, and styled with **Tailwind CSS**.

## ✨ Features

- ⏲️ Real-time digital clock with **HH : MM : SS** format
- 📅 Displays full date: day, date, month, year
- 🎞️ Smooth sliding number animations for time updates
- 🌗 Supports theme switching via `next-themes`
- 🎨 Fully styled with **Tailwind CSS**

## 🛠️ Tech Stack

- 🧠 **Next.js 15** – React framework
- ⚛️ **React 19** – UI library
- 🎨 **Tailwind CSS 4** – Utility-first CSS
- 🧱 **shadcn/ui** – Reusable UI components
- ⏱️ **date-fns 4** – Time & date formatting
- 🖼️ **Lucide React** – Icons for UI
- 🛡️ **TypeScript 5** – Type safety

### 🔵 Clock Component

- Displays **hours, minutes, seconds, and meridiem (AM/PM)**
- Updates **every second** using `date-fns`
- Shows **full date** in a readable format
- Includes **sliding number animation** for smooth transitions

## 🚀 Getting Started

To run this project locally, follow these steps:

### 1. Install Dependencies

Install all required packages using your preferred package manager:

```bash
# With npm
npm install

# With yarn
yarn install

# With pnpm
pnpm install
```

### 2. Start the Development Server

Once dependencies are installed, launch the local server using one of the following commands:

```bash
# With npm
npm run dev

# With yarn
yarn dev

# With pnpm
pnpm dev
```
